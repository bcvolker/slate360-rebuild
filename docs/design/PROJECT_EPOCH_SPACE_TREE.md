# Project / epoch / space tree

User-facing hierarchy. Spaces are logical time ranges on a continuous recording. Do not make the author split MP4 files merely to create spaces.

```
PROJECT
  Sep 2, 2026
    Exterior
      East
      West
      Drone
    Level 1
      Lobby
      Corridor
      Room 205
    Above Ceiling
    Roof
```

## Recording vs space

A continuous recording stays **one clip** when practical.

Split into a separate clip only for:

- recording stop
- device change
- aerial
- pocket capture
- special inspection
- separate floor / session

## Edges

Continue · Enter · Exit · Upstairs · Downstairs · Take Off · Land · View Inspection

Authoring marks `Start space here` / `End space here` in Studio only. Those controls stay off the public share route.

## Path stations

If a walk already has waypoints (HouseWalk has them), reduce to first / turns / doorways / chapter boundaries / temporal spacing. Show 3–5 stations in the sphere, not eleven ticks.
